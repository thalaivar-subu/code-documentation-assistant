An LLM that answers from your codebase — and shows its work

RAG means: before the model answers, go fetch the actual relevant text, and hand that to the model instead of trusting its memory. Simple in one sentence, easy to get subtly wrong in practice. Why not just ask the model

Naive RAG gets ~85% of the way on prose. Code breaks it.

Split the text into fixed-size chunks, embed them, grab the top few by similarity, stuff them in a prompt — that's naive RAG, and it's a reasonable start for documents. Source code has different failure modes, and each one needed a real fix, not a bigger model.

Where naive RAG breaks on code

  • Fixed-size splitting cuts a function in half mid-body
  • Nobody phrases a question the way the code names things
  • Embedding similarity never actually reads the question against the candidate
  • “How does login work?” spans four files — one retrieval pass won't reach all of them
  • A fluent, wrong-sounding-right answer looks identical to a correct one

What this pipeline does instead

  • AST-aware chunking — split at function/class boundaries with tree-sitter, never mid-body
  • Hybrid retrieval — dense embeddings and BM25 keyword search, run in parallel
  • Cross-encoder reranking — a slower model reads query and candidate together
  • A loop, not a single pass — retrieve, grade “enough?”, go again if not
  • Citation verification — every claim checked against the exact text the model saw

Two pipelines: index the repo once, then answer questions

Ingest runs once per repo (then incrementally, as files change). Query runs once per question — and can loop back on itself when one pass isn't enough. Every output below is real, copy-pasted from an actual run.

None of this is locked in

Every stage above runs in-process by default. Each can be swapped for a service.

Nothing here requires Docker or a running service — the default is "clone the repo, npm install, go." But every stage that touches a model or a store sits behind a small interface, so a heavier, managed alternative is a config change, not a rewrite.
