## Note on drift (2026-07-25)

This table describes the **original architecture plan** (LangGraph, Qdrant, Ollama, hexagonal
ports/adapters with a container). All 12 pipeline stages (Ingest 1–4, Query 1–8) plus the API and
UI are now built, and the ports/container abstraction has **still** not been needed — modules
import each other directly, and each stage owns its own adapters (`vector-store.ts`,
`lexical-store.ts`, etc.) without a `ports.ts`/`container.ts` layer. That's a legitimate
simplification for a stage-gated build, not an abandoned decision — but since the full pipeline is
now done and `container.ts`/`ports.ts` still don't exist, **0009 should be marked historical**
rather than left implying code that doesn't exist.

**Also not implemented:** the "incremental indexing" design (`indexed_commit_sha` + manifest,
`git diff` on re-index, changed-files-only) described in the original plan and in
`docs/ARCHITECTURE.md` §2 was never built. Re-indexing today does a full rescan every time (cheap
only because of content-hash-cached embeddings and idempotent upserts, not because of diffing).
There's also no push notification / webhook of any kind — re-indexing only happens when something
explicitly calls `/index` again. See `docs/ARCHITECTURE.md`'s "Incremental re-indexing" note for
the full picture, including a real, still-open bug in the cached-clone reuse path.
